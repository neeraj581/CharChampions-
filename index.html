TraceStep

Dry-run a C++ loop one check at a time

How to use TraceStep

  1. Paste one C++ loop into the code box, or press Load example loop.
  2. Press Next to run the next loop check.
  3. Read the dry run table and the check strip to see where the loop goes wrong.
  4. Press Edit code to fix it, then trace again to check the fix.

Keyboard shortcuts

  • Right arrow: Next
  • Left arrow: Back
  • R: Reset

Shortcuts work when the code box isn't focused. Tab and Shift+Tab move between controls.

Code TraceStep can run

int variables, for and while loops, if and else, break and continue, + − * / %, comparisons, && and ||, and cout. A full program with #include and int main() works too.

Not yet: cin, arrays, functions, strings, decimals.
